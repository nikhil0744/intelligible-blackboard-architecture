# Historical documentation archive

Archived on 12 November 2026 to allow the team to assess the current implementation without competing old roadmaps.

All nine previously collected planning, review, and mixed guide/presentation documents are retained in [plans/](plans/README.md). The existing `fully_implemented/` and `not_started/` classifications are preserved; partially implemented and mixed documents remain directly under `plans/`.

These documents are inactive historical records. Their deadlines, assignments, completion percentages, recommendations, and presentation claims do not define the current project plan. Archiving a review does not establish that its findings have been fixed.

Use [the current project status review](../PROJECT_STATUS.md) as the baseline for discussing further work. It records verified behavior, reproduced failures, limits of validation, and improvement opportunities without assigning a new schedule or individual responsibilities.

Document contents are preserved except for relative navigation links affected by relocation. Source code, tests, benchmark artifacts, notebook cells, and frontend implementation have not been changed by this documentation cleanup. Setup/reference material, assistant templates, and presentation binaries without a dedicated implementation plan remain in place.

Some archived files were previously ignored local documents. A scoped `.gitignore` exception makes the archive eligible for version control. Nothing has been staged, committed, or pushed as part of this cleanup.
